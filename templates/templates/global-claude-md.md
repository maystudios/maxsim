# MAXSIM Global Instructions

MaxsimCLI is installed in this Claude Code environment.

## Quick Start

Run `/maxsim:go` -- it auto-detects your project state and proposes the right next action.

## Available Commands

| Command | Purpose |
|---------|---------|
| `/maxsim:go` | Auto-dispatch: detects project state and does the right thing |
| `/maxsim:init` | Initialize MaxsimCLI in a project |
| `/maxsim:plan [N]` | Plan a specific phase |
| `/maxsim:execute [N]` | Execute a planned phase |
| `/maxsim:quick [desc]` | Quick task (simplified flow) |
| `/maxsim:debug [desc]` | Debug a specific issue |
| `/maxsim:improve [metric]` | Autonomous optimization loop |
| `/maxsim:fix-loop [cmd]` | Autonomous error repair |
| `/maxsim:debug-loop [symptom]` | Autonomous bug hunting |
| `/maxsim:security [scope]` | Security audit (read-only) |
| `/maxsim:progress` | Show project status + recommendation |
| `/maxsim:settings` | Configure MaxsimCLI |
| `/maxsim:help` | Show available commands |

## Notes

- Project-level `CLAUDE.md` is auto-generated by the MaxsimCLI installer (`npx maxsimcli`). You do not need to create it manually.
- This global file at `~/.claude/CLAUDE.md` provides commands to every Claude Code session, regardless of which project you open.
- Use `/maxsim:help` to see detailed command reference, or visit https://maxsimcli.dev for full documentation.
